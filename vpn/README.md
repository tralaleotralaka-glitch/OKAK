# PROPYSK — нативный Android‑клиент (VPN‑каркас)

Реальный системный VPN на `android.net.VpnService`, без WebView, без AndroidX,
без ссылок и QR. Интерфейс — **огромная круглая кнопка включения**, статус,
таймер и счётчик трафика, плюс **настройки**: смена темы (тёмная/светлая) и
**список DNS** (Cloudflare, Google, Quad9, AdGuard, Яндекс, OpenDNS, Comodo,
Norton и др.) — выбранный DNS применяется в туннеле.

## Что здесь настоящее

- `LocalVpnService extends VpnService` — поднимает VPN‑интерфейс (`builder.establish()`),
  читает пакеты из tun‑дескриптора, считает байты, держит foreground‑уведомление.
- `MainActivity` — большая кнопка; запрос согласия системы через `VpnService.prepare()`,
  старт/стоп сервиса, живой таймер и счётчик.
- Компилируется и устанавливается; Android показывает значок VPN, пока сервис жив.

## Честная граница

У каркаса **нет внешнего сервера**, поэтому трафик никуда не пересылается.
По умолчанию `FORWARD_ALL = false` — маршрут `0.0.0.0/0` не добавляется и устройство
остаётся в сети (VPN‑интерфейс есть, но это демо‑туннель). Это осознанно: без апстрима
«рабочий» VPN невозможен, а делать вид, что он есть, мы не хотим.

Точка расширения помечена в `LocalVpnService.run()`:

```java
// TODO: здесь пакеты передаются в настоящий туннель/сервер
// (WireGuard / SOCKS / HTTPS-connect).
```

## План до «рабочего» VPN

1. Выбрать транспорт: **WireGuard** (рекомендую) или SOCKS5/HTTPS‑connect.
2. Поднять сервер (VPS): для WireGuard — `wg`/`wg-easy`; выдать клиенту ключи/конфиг.
3. В `run()` заменить «считаем и опускаем» на пересылку пакетов в туннель
   (для WireGuard — встроить `wireguard-go` через JNI или готовую библиотеку
   `com.wireguard.android`; для SOCKS — userspace‑стек, напр. tun2socks).
4. Поставить `FORWARD_ALL = true`, когда апстрим готов, чтобы маршрутизировать весь трафик.
5. Проверять на реальном устройстве/эмуляторе — в этой песочнице ни эмулятора, ни
   сервера нет, поэтому поведение туннеля end-to-end здесь не проверялось; CI проверяет компиляцию.

## Сборка

```bash
cd vpn
./gradlew assembleDebug   # APK: app/build/outputs/apk/debug/app-debug.apk
```

CI собирает его автоматически и кладёт в релиз `apk-<ветка>` (файл `OKAK-VPN-<версия>-debug.apk`).
