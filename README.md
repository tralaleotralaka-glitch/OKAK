# OKAK — умный русскоязычный бот

Чат-ассистент на русском языке. Отвечает на вопросы о **времени и дате**, считает **математику**
(арифметика, проценты, корни, уравнения, производные, интегралы), знает **базовые факты** из истории,
литературы, науки, географии и технологий и — при подключении LLM — отвечает на любые вопросы.

- ⚡ Ответ обычно за **несколько миллисекунд** (локальный режим). В AI-режиме есть жёсткий таймаут:
  общий бюджет ответа — 6 с, модель ждём не дольше 5 с, после этого отвечает локальный движок.
- 🎨 Современный интерфейс: тёмная и светлая темы, анимации, подсказки, индикатор печати,
  отображение времени ответа и текущего времени сервера. Без сборки и внешних CDN.
- 🔒 Безопасность: математика не выполняет произвольный Python-код (белый список токенов и функций).

## Быстрый старт

```bash
python3 -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt                 # sympy — для уравнений и производных (необязательно)
python3 app.py                                  # http://localhost:8000
```

Открой `http://localhost:8000` и напиши, например:

| Запрос | Что будет |
|---|---|
| `который час?` / `какое сегодня число` | точное время и дата (часовой пояс `Europe/Moscow`) |
| `сколько времени в Токио` | время в другом городе |
| `сколько дней до нового года` / `сколько дней до 8 марта` | счётчик дней до события |
| `сколько будет 15% от 480` | `15% от 480 = 72` |
| `корень из 144`, `2 в степени 10`, `факториал 6` | вычисления |
| `реши x^2 - 5x + 6 = 0` | `x₁ = 2; x₂ = 3` |
| `производная от x^3 + 2x`, `интеграл от 2x` | символьное дифференцирование и интегрирование |
| `кто такой Пушкин?`, `что такое ДНК`, `столица Франции` | знания из встроенной базы |
| `расскажи анекдот`, `что ты умеешь` | small talk |

## Режимы работы

**Локальный режим** (по умолчанию, ключи не нужны) — время, дата, математика, столицы и
около 170 встроенных фактов в `okak/data/knowledge_ru.json`. Вопросы вне базы получают честный ответ «не знаю».

**AI-режим** — если задан ключ, вопросы вне базы отправляются в OpenAI-совместимый API
(OpenAI, Ollama, LM Studio, OpenRouter и т.п.). Модель получает текущую дату и время и последние
реплики диалога. Если модель не ответила за 5 секунд — отвечает локальный движок.

```bash
# OpenAI
export OKAK_LLM_API_KEY=sk-...
export OKAK_LLM_MODEL=gpt-4o-mini

# Локальная модель через Ollama (ключ любой, но обязательный)
export OKAK_LLM_API_KEY=ollama
export OKAK_LLM_BASE_URL=http://localhost:11434/v1
export OKAK_LLM_MODEL=qwen2.5:7b
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8000` | порт сервера |
| `HOST` | `0.0.0.0` | адрес для прослушивания |
| `OKAK_TZ` | `Europe/Moscow` | часовой пояс для времени и дат |
| `OKAK_BUDGET` | `6.0` | общий бюджет времени ответа, с |
| `OKAK_LLM_API_KEY` / `OPENAI_API_KEY` | — | ключ для AI-режима (без него AI выключен) |
| `OKAK_LLM_BASE_URL` | `https://api.openai.com/v1` | базовый URL OpenAI-совместимого API |
| `OKAK_LLM_MODEL` | `gpt-4o-mini` | имя модели |
| `OKAK_LLM_TIMEOUT` | `5.0` | таймаут запроса к модели, с |

## API

- `POST /api/chat` — тело `{"message": "...", "history": [{"role": "user|assistant", "content": "..."}]}`;
  ответ `{"reply", "intent", "source", "elapsed_ms"}`.
- `GET /api/health` — статус и режим (`local` / `ai`).
- `GET /api/time` — текущее время сервера.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты покрывают математику, время и даты, базу знаний, маршрутизацию, защиту от инъекций,
поведение при таймаутах LLM и требование «ответ быстрее 7 секунд».

## Структура

```
app.py                 HTTP-сервер (stdlib) и раздача интерфейса
okak/
  engine.py            маршрутизация вопроса и бюджет времени
  timeinfo.py          время, даты, города, дни до события
  mathsolver.py        вычисления (ast-интерпретатор) и sympy (уравнения, производные, интегралы)
  knowledge.py         поиск по базе знаний с учётом падежей, столицы стран
  smalltalk.py         приветствия, помощь, шутки
  llm.py               клиент OpenAI-совместимого API с таймаутом
  data/knowledge_ru.json  база знаний (JSON — легко дополнять)
static/                интерфейс: index.html, styles.css, app.js
tests/test_okak.py     тесты
```

### Как дополнить базу знаний

Добавьте объект в `okak/data/knowledge_ru.json`:

```json
{ "topic": "история", "keywords": ["куликов", "куликовская битв"], "answer": "Куликовская битва произошла в 1380 году." }
```

Ключевое слово — основа слова (`столиц` найдёт «столица», «столицы», «столице»).
Фраза из нескольких слов, например `"куликовская битв"`, требует совпадения всех слов.

## Ограничения

- Без AI-режима бот знает только то, что есть в базе знаний (около 170 записей, столицы около 50 стран). Для широкой эрудиции нужен LLM-ключ.
- База знаний ищет по основам слов: редкие термины, имена и синонимы без записи в базе не найдутся — их можно добавить в `okak/data/knowledge_ru.json`.
- Символьная математика требует `sympy`; без него уравнения и производные недоступны.
- Тригонометрические функции считают в радианах.
