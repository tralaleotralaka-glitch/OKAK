# VOX AI 🎙️

Голосовой ИИ-ассистент с настраиваемым API: свой ключ, своя модель, свой характер и голос.
Без зависимостей — только Node.js 20+ и встроенный `fetch`.

![VOX AI](public/logo.svg)

## Возможности

- **Чат с потоковыми ответами** — текст печатается по мере генерации, есть кнопка «Стоп».
- **Настройки API** — провайдер, API-ключ, Base URL, модель; кнопки «Проверить подключение» и «Загрузить модели».
- **9 провайдеров из коробки** — OpenAI, OpenRouter, DeepSeek, Groq, Mistral, Together, xAI, Ollama (локально), плюс свой OpenAI-совместимый сервер (LM Studio, vLLM, прокси).
- **Голос** — распознавание речи (микрофон) и озвучка ответов: голосом браузера офлайн или через `/audio/speech` провайдера.
- **Характер** — системный промпт с готовыми пресетами, язык ответов, температура, top-p, лимит токенов, глубина памяти.
- **Удобство** — тёмная/светлая тема, экспорт диалога в TXT, копирование и перегенерация ответа, адаптивная мобильная вёрстка.

## Запуск

```bash
npm start
```

Откройте <http://localhost:4173>. Порт можно переопределить: `PORT=8080 npm start`.

Зависимостей нет, `npm install` не требуется. Для авто-перезапуска: `npm run dev`.

## Как подключить API

1. Откройте **«Настройки и API»** (кнопка внизу слева).
2. Выберите провайдера — ссылка на страницу получения ключа появится под полем.
3. Вставьте **API-ключ**.
4. Укажите **модель** (или нажмите «Загрузить», чтобы получить список у провайдера).
5. Нажмите **«Проверить подключение»** — покажет статус, задержку и endpoint.
6. «Сохранить» — и можно общаться.

Локальные модели (Ollama): провайдер `Ollama`, ключ не нужен, `Base URL` = `http://localhost:11434/v1`, модель, например, `llama3.2`.

## Безопасность ключа

- Ключ хранится **только на сервере** в `data/settings.json` (права `600`, каталог в `.gitignore`).
- Браузер ключ никогда не получает: наружу отдаётся только маска вида `sk-…7f3a`.
- Запросы к провайдеру идут через серверный прокси `/api/chat`, поэтому ключ не виден в DevTools.

> Если разворачиваете приложение в интернете, добавьте аутентификацию перед ним (например, reverse-proxy с basic-auth) — иначе любой, кто откроет сайт, сможет тратить ваши токены.

## API сервера

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/config` | провайдеры, дефолты, публичные настройки |
| `GET` | `/api/settings` | текущие настройки (ключ замаскирован) |
| `PUT` | `/api/settings` | сохранить настройки (`apiKey: ""` — не менять, `null` — удалить) |
| `POST` | `/api/settings/reset` | сброс к значениям по умолчанию |
| `POST` | `/api/test` | проверка связи с провайдером |
| `GET` | `/api/models` | список моделей провайдера |
| `POST` | `/api/chat` | чат (SSE-поток или JSON) |
| `POST` | `/api/tts` | озвучка через провайдера (mp3) |
| `POST` | `/api/stt` | распознавание речи (raw-аудио в теле) |
| `GET` | `/api/health` | статус сервера |

Пример запроса:

```bash
curl -X POST http://localhost:4173/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"Привет!"}]}'
```

Переменные окружения: `PORT`, `HOST`, `VOX_TTS_MODEL`, `VOX_TTS_VOICE`.

## Горячие клавиши

- `Enter` — отправить, `Shift+Enter` — новая строка
- `Space` (когда поле пустое и фокус не в вводе) — включить микрофон
- `Esc` — закрыть настройки / остановить запись / прервать ответ

## Структура

```
server/
  index.js      HTTP-сервер, прокси к провайдеру, TTS/STT
  providers.js  каталог провайдеров и сообщения об ошибках
  store.js      хранение и валидация настроек
public/
  index.html    интерфейс
  styles.css    тёмная/светлая тема
  app.js        чат, голос, панель настроек
```

## Совместимость голоса

Распознавание речи работает в Chrome и Edge (Web Speech API). Озвучка браузером доступна везде, где есть `speechSynthesis`; в остальных случаях включите «Озвучка через API» (OpenAI и совместимые провайдеры с `/audio/speech`).
