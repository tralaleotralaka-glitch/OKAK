# DNS Compass

Лёгкое Android-приложение для проверки ответов и времени отклика нескольких публичных DNS-over-HTTPS резолверов. Введите домен (по умолчанию `youtube.com`) и сравните результаты.

## APK

APK автоматически собирается GitHub Actions для каждого push и доступен в разделе **Actions → Build Android APK → Artifacts** как `dns-compass-debug-apk` (срок хранения — 30 дней). Локальная сборка: `gradle assembleDebug` при установленном Android SDK 35 и JDK 17.

Это диагностическое приложение: оно не меняет системные настройки DNS, не является VPN/прокси и не перенаправляет трафик. Измеряется только DNS-запрос; это не тест скорости YouTube. Результаты DNS не гарантируют доступность сайтов и не обходят ограничения сети. При проверке введённый домен отправляется выбранным DNS-провайдерам по HTTPS.
