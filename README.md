# 👻 Шёпот — анонимный SMS-мессенджер

Веб-мессенджер, в котором вы пишете **номер телефона + текст**, а получателю приходит
**обычное SMS с номера сервиса** — без вашего имени и номера. Ваша личность получателю
недоступна.

## Как это работает

```
ВЫ (веб-интерфейс)          СЕРВЕР «ШЁПОТ»             SMS-ПРОВАЙДЕР           ПОЛУЧАТЕЛЬ
 phone + text  ──────────►  нормализация номера   ──►  Twilio / SMS.ru  ──►  «Привет!»
                            антиспам-лимиты                                   (номер сервиса)
                            запись в SQLite
```

1. Вы открываете веб-интерфейс, вводите номер телефона и текст.
2. Сервер нормализует номер (E.164), проверяет лимиты антиспама и сохраняет сообщение в SQLite.
3. Сообщение уходит через SMS-провайдера **от имени сервиса** — получатель видит обычную
   SMS-ку с незнакомого номера и не может узнать, кто отправил.
4. Если получатель ответит на SMS, ответ по вебхуку провайдера попадает в тот же диалог —
   переписка двусторонняя, при этом вы тоже остаётесь анонимны.

## Режимы отправки

| Режим | Что делает | Когда использовать |
|-------|------------|--------------------|
| `demo` (по умолчанию) | SMS не отправляется по-настоящему — сообщение появляется во вкладке **«Телефон получателя»** (симулятор) | Демо, разработка |
| `twilio` | Реальная отправка через [Twilio](https://www.twilio.com) | Международные номера |
| `smsru` | Реальная отправка через [SMS.ru](https://sms.ru) | Номера РФ и СНГ |

Режим и ключи задаются в файле `.env` (см. `.env.example`).

## Android-приложение (APK)

Тот же мессенджер, упакованный в нативное Android-приложение (WebView + локальная логика,
без сервера). Сборка происходит автоматически через GitHub Actions при каждом пуше в ветку.

**Скачать APK:**
```
https://github.com/tralaleotralaka-glitch/OKAK/releases/latest/download/shepot.apk
```
(страница релизов: `Releases` в репозитории)

При установке разрешите установку из неизвестных источников. В приложении есть вкладка
**«Настройки»**: выбор провайдера (демо / Twilio / SMS.ru) и ключей — они хранятся только
на устройстве. SMS отправляется через API провайдера с номера сервиса.

Исходники приложения: `android/` (Java, без зависимостей), сборка: `android/build-apk.sh`
(aapt → javac → d8 → zipalign → apksigner), workflow: `.github/workflows/build-apk.yml`.
Ключ подписи: `android/signing/shepot.p12` (пароль `shepot2026`, только для отладочных сборок).

## Быстрый старт (веб-версия)

```bash
./run.sh          # или: cd app && python3 server.py
# откройте http://localhost:8000
```

Никаких зависимостей: только Python 3.8+ из стандартной библиотеки. База — SQLite
(`var/data.db`), создаётся автоматически.

## Подключение реальной отправки

```bash
cp .env.example .env
```

**Twilio:**
```env
SMS_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxxxxxx
TWILIO_AUTH_TOKEN=ваш_токен
TWILIO_FROM=+15005550006
```
В консоли Twilio настройте webhook входящих SMS на
`https://ваш-домен/webhook/twilio?key=СЕКРЕТ` — тогда ответы получателей будут
появляться в диалоге.

**SMS.ru:**
```env
SMS_PROVIDER=smsru
SMSRU_API_ID=ваш_api_id
```
Callback входящих — `https://ваш-домен/webhook/smsru?key=СЕКРЕТ`.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| `GET`  | `/api/config` | активный провайдер и лимиты |
| `POST` | `/api/threads` | создать/найти диалог `{phone}` |
| `GET`  | `/api/threads` | список диалогов |
| `GET`  | `/api/threads/:id/messages` | сообщения диалога |
| `POST` | `/api/threads/:id/messages` | отправить анонимное SMS `{body}` |
| `GET`  | `/api/demo/inbox?phone=…` | демо: что «пришло» получателю |
| `POST` | `/api/demo/reply` | демо: ответ получателя `{phone, body}` |
| `POST` | `/webhook/twilio` | входящие SMS Twilio |
| `GET/POST` | `/webhook/smsru` | входящие SMS SMS.ru |

## Защита от злоупотреблений

- **Лимиты**: не более `RATE_PHONE` (по умолч. 5) сообщений в час на один номер
  получателя и `RATE_IP` (30) — с одного IP.
- **Ограничение длины** сообщения (`MAX_LEN`, по умолч. 1000 символов).
- **Номер сервиса** в качестве отправителя: сервис не подменяет чужие имена/номера.

⚠️ **Ответственность.** Анонимность — для честных целей (обратная связь, знакомства,
информирование). Отправлять угрозы, спам, клевету и материалы, запрещённые законом,
нельзя. Как оператору сервиса вам могут потребоваться: логирование IP, модерация,
соблюдение местного законодательства о связи и персональных данных.
