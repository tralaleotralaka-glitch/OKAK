# MySENGER

Простой мессенджер в браузере (HTML + CSS + JS, без зависимостей).

## Возможности
- **＋ в правом нижнем углу** — ввод номера телефона → появляется кнопка **«Применить»** → открывается чат с этим номером (если чат уже есть — открывается он).
- **⚙ в правом верхнем углу** — настройки: смена аватарки и имени, светлая/тёмная тема.
- При выходе из настроек с несохранёнными изменениями предлагается **сохранить**.
- Всё сохраняется в `localStorage`: переписка, контакты, настройки, черновики и открытый экран.

## Запуск
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000 (или просто откройте `index.html`).
