# ProxyTG

Клиент для работы с MTProto-прокси Telegram: генерирует корректные fake-TLS
секреты и ссылки, держит «белые списки» (домены маскировки SNI и подсети
Cloudflare), умеет подтягивать публичные списки прокси и открывать их в Telegram.

Интерфейс похож на референс, но переработан: тёмная тема, карточка статуса,
нижняя навигация **Прокси / Списки / Логи / Ещё**. Название — **ProxyTG**.

## Что реально работает

- **Генератор секрета Fake-TLS.** Формат `ee + 16 случайных байт + hex(SNI-домен)` —
  тот же, что используют mtg и официальные клиенты (MTProxySecretType2).
  Домен берётся из белого списка SNI.
- **Ссылки.** Собираются `https://t.me/proxy?server=…&port=…&secret=…` и
  `tg://proxy?…`. Копирование, QR-код и «Открыть в Telegram» (deep-link —
  на телефоне с Telegram прокси добавится в один тап).
- **Белые списки.** Домены маскировки SNI и официальные IPv4-подсети Cloudflare
  (сняты с `cloudflare.com/ips-v4`). Оба списка редактируются и сохраняются.
  Кнопка **CF** подставляет случайный IP из подсети.
- **Публичные прокси.** «Обновить из интернета» тянет свежие списки
  (источники — raw.githubusercontent.com, у него открыт CORS), парсит ссылки
  и раскладывает в «Мои прокси». Источники редактируются в настройках.
- **Логи и сохранение.** Все действия пишутся в журнал; всё состояние —
  в `localStorage` (`proxytg.state.v1`) и переживает перезапуск.

## Важная честность

ProxyTG — **клиент**. Он собирает корректную конфигурацию и ссылки, но сам
трафик не несёт: для этого нужен запущенный MTProto-сервер. Кнопка
«Как поднять свой сервер» отдаёт готовую docker-команду
(`nineseconds/mtg:2`, поддерживает Fake-TLS) — подставьте её в свой VPS
и получите работающий прокси, а ProxyTG соберёт под него ссылку.

Публичные прокси из списков — чужие серверы. Их доступность не гарантируется,
а владелец сервера видит факт подключения. Используйте на свой риск; для
приватности поднимайте свой сервер.

## Форматы (шпаргалка)

| Вид | Секрет | Комментарий |
| --- | --- | --- |
| Fake-TLS | `ee` + 32 hex + hex(домен) | маскировка под HTTPS, SNI = домен |
| Secure | `dd` + 32 hex | random-padded intermediate |
| Classic | 32 hex | без маскировки, ловится DPI |
| Base64 | base64-вариант | Telegram принимает и его |

## Запуск и тесты

```bash
# веб (из корня репозитория)
npm start                # и откройте http://localhost:8000/proxytg/

# тесты ядра и интерфейса (jsdom)
npm test                 # гоняет и proxytg/tests/*.test.js
```

APK собирается тем же workflow, что описан в корневом README: в релизе
`apk-<ветка>` лежит `ProxyTG-<версия>-debug.apk`.
